\section{Assoliment dels objectius}

Els objectius del projecte, definits al Capítol 1, s'han assolit en la seva totalitat:

\begin{enumerate}
    \item \textbf{Implementar un pipeline ETL robust} -- \textbf{ASSOLIT}. Pipeline complet amb Node.js que extreu, transforma i desa dades de les APIs de Socrata en JSON versionat.
    
    \item \textbf{Crear un frontend interactiu amb quatre panells} -- \textbf{ASSOLIT}. Quatre dashboards amb React: mapa (Leaflet), evolució temporal (Recharts), correlació (gràfics de dispersió), i alertes (semàfor + tendències).
    
    \item \textbf{Assegurar l'automatització} -- \textbf{ASSOLIT}. Dos workflows de GitHub Actions: ETL diari a les 02:00 UTC i desplegament automàtic a GitHub Pages.
    
    \item \textbf{Implementar lògica de detecció de sequera} -- \textbf{ASSOLIT}. Sistema de classificació per llindars i algoritme de comparació temporal per detectar tendències.
    
    \item \textbf{Documentar adequadament} -- \textbf{ASSOLIT}. Memòria completa amb decisions d'arquitectura, implementació i guies d'ús.
\end{enumerate}

Pel que fa als requisits (Capítol 5), tots els funcionals (RF-1 a RF-6) s'han assolit completament. A més, s'han implementat proves automatitzades amb Vitest per als mòduls ETL i components frontend.

%----------------------------------------------------------------------------------------

\section{Principals resultats}

\begin{itemize}
    \item \textbf{Sistema complet}: Plataforma web funcional amb dades de 9 embassaments i 200+ estacions meteorològiques de Catalunya.
    \item \textbf{Cost zero}: GitHub Actions per a l'ETL i GitHub Pages per al frontend permeten funcionament sense costos d'infraestructura.
    \item \textbf{Codi obert}: Tot el projecte és públic a GitHub, reutilitzable per a altres regions o tipus de dades.
    \item \textbf{Més enllà del portal oficial}: Ofereix correlacions automàtiques i alertes de sequera integrades que no estan disponibles al portal d'ACA.
\end{itemize}

%----------------------------------------------------------------------------------------

\section{Aportacions personals}

\begin{itemize}
    \item \textbf{Arquitectura desacoblada}: Separació ETL/frontend mitjançant JSON, sense servidors de backend ni bases de dades.
    \item \textbf{Finestra lliscant}: Sistema que manté un fitxer principal amb 2 anys de dades i arxiva l'historial separat per anys.
    \item \textbf{Detecció de tendències}: Comparació del valor actual amb el valor de fa 7 dies per detectar millora o deteriorament.
    \item \textbf{CI/CD complet}: Dos workflows coordinats amb gestió de credencials i optimització de recursos.
\end{itemize}

\section{Aprenentatge realitzat}

\subsection{Aprenentatge tècnic}

\begin{itemize}
    \item \textbf{Node.js i ETL}: Disseny i implementació de pipelines robusts amb gestió d'errors i reintents.
    \item \textbf{React avançat}: \texttt{React.lazy}, \texttt{Suspense}, hooks personalitzats i gestió d'estat.
    \item \textbf{Visualització de dades}: Recharts i Leaflet amb optimització per a grans conjunts de dades.
    \item \textbf{CI/CD}: Workflows complexos amb cron, permisos i desplegament automàtic.
\end{itemize}

\subsection{Aprenentatge en gestió}

\begin{itemize}
    \item \textbf{Estimació precisa}: Error de només 3,2\% respecte a les 330 hores estimades (341 hores reals).
    \item \textbf{Gestió de desviacions}: Reavaluació proactiva de prioritats sense perdre la visió global.
    \item \textbf{Proves d'usabilitat}: Les proves automatitzades no substitueixen la validació amb usuaris reals.
    \item \textbf{Documentació}: Eina de treball que facilita desenvolupament i manteniment.
\end{itemize}

En conjunt, aquest projecte ha representat una oportunitat valuosa per aplicar coneixements del grau en un context real, desenvolupant competències tècniques i professionals per a la carrera futura.
