\section{Implementació del pipeline ETL}

El pipeline ETL s'ha implementat com un conjunt de mòduls Node.js estructurats segons el patró de pipeline modular:

\subsection{Extracció}
Dos extractors independents (\texttt{EmbassamentExtractor} i \texttt{PrecipitationExtractor}) utilitzen \texttt{axios} per obtenir dades de les APIs Socrata de la Generalitat \cite{gencat_dades, socrata}. Suporten mode incremental (diari) i sincronització completa (\texttt{--full-sync}). La configuració es gestiona amb \texttt{dotenv}.

\subsection{Transformació}
Els transformadors normalitzen dates a ISO 8601, eliminen duplicats, calculen percentatges d'ocupació i classifiquen alertes de sequera (crític \textless20\%, avís 20-50\%, normal 50-75\%, òptim \textgreater75\%). Per a precipitació, s'implementa una finestra lliscant de 2 anys.

\subsection{Càrrega}
\texttt{DataLoader} desa les dades en fitxers JSON amb metadades, fusió incremental per evitar duplicats, i neteja automàtica de còpies antigues (més de 30 dies).

%----------------------------------------------------------------------------------------

\section{Implementació del frontend}

\subsection{Estructura}
Aplicació SPA amb React 18 \cite{react}, React Router 6 i gestió d'estat amb hooks de React. Els components es carreguen asíncronament amb \texttt{React.lazy()} i \texttt{Suspense} per a code splitting.

\subsection{Gestió de dades}
\texttt{waterDataService.js} encapsula l'accés a dades mitjançant \texttt{axios}, proporcionant filtres per data i estació, agrupació per nom, i càlcul de colors d'estat.

\subsection{Visualitzacions}
\begin{itemize}
    \item \textbf{Recharts 2} \cite{recharts}: Gràfics de línies, dispersió i KPIs amb integració nativa amb React.
    \item \textbf{Leaflet 1} \cite{leaflet}: Mapa interactiu amb markers i popups informatius.
\end{itemize}

L'estil utilitza Sass \cite{sass} amb metodologia BEM i CSS Grid/Flexbox per a disseny responsiu mobile-first.

%----------------------------------------------------------------------------------------

\section{Automatització amb GitHub Actions}

Dos workflows coordinats \cite{github_actions}:

\textbf{ETL Pipeline (\texttt{etl-pipeline.yml})}: S'executa diàriament a les 02:00 UTC (cron) o manualment. Fa checkout, instal·la dependències, executa l'ETL, copia fitxers JSON a \texttt{frontend/public/data/}, i fa commit/push amb \texttt{[skip ci]} per evitar bucles.

\textbf{Desplegament (\texttt{deploy-frontend-pages.yml})}: S'activa a push a \texttt{main}. Construeix el frontend amb Vite \cite{vite} i desplega a GitHub Pages \cite{github_pages}.

\section{Proves realitzades}

\textbf{Proves ETL}: Validació de cada fase (extractors, transformadors, carregadors) amb Vitest, verificant estructures de dades, normalització, fusió i neteja.

\textbf{Proves frontend}: Verificació de \texttt{waterDataService}, components de visualització (Recharts, Leaflet) i navegació React Router.

\textbf{Proves d'integració}: Execució completa amb dades reals, simulació d'errors d'API i validació del flux complet.

\section{Estructura del lloc web i captures de pantalla}

El lloc web es composa de quatre panells de visualització interconnectats, accessibles mitjançant una barra de navegació superior. A continuació es descriu l'estructura i es mostren captures representatives de cada panell.

\subsection{Estructura de navegació}

\begin{itemize}
    \item \textbf{Dashboard (pàgina principal)}: Vista general amb mapa interactiu i KPIs principals
    \item \textbf{Reservoirs}: Evolució temporal dels nivells d'embassaments
    \item \textbf{Weather}: Correlació entre precipitació i nivells d'embassament
    \item \textbf{About}: Informació sobre el projecte i les seves fonts de dades
\end{itemize}

\subsection{Dashboard principal - Mapa interactiu}

\begin{figure}[ht]
\centering
\includegraphics[width=\textwidth]{Figures/captura_dashboard1.png}
\caption{Dashboard principal: mapa interactiu amb markers dels 9 embassaments de Catalunya i KPIs dinàmics.}
\label{fig:dashboard1}
\end{figure}

El Dashboard principal presenta un mapa interactiu basat en Leaflet que mostra la ubicació geogràfica dels 9 embassaments de Catalunya. Cada marker inclou un popup informatiu amb el nom, percentatge d'ocupació i volum embassat. A la part superior es mostren KPIs dinàmics (capacitat total del sistema, percentatge mitjà d'ocupació) que s'actualitzen en funció dels filtres aplicats.

\subsection{Evolució temporal}

\begin{figure}[ht]
\centering
\includegraphics[width=\textwidth]{Figures/captura_dashboard2.png}
\caption{Dashboard d'evolució temporal: gràfic de línies amb comparació múltiple d'embassaments i selector de dates.}
\label{fig:dashboard2}
\end{figure}

El panell d'evolució temporal utilitza Recharts per mostrar la trajectòria del nivell d'ocupació dels embassaments al llarg del temps. L'usuari pot seleccionar rangs de dates, comparar múltiples embassaments simultàniament, i fer zoom en períodes específics per detectar tendències.

\subsection{Correlació clima-aigua}

\begin{figure}[ht]
\centering
\includegraphics[width=\textwidth]{Figures/captura_dashboard3.png}
\caption{Dashboard de correlació clima-aigua: gràfic de dispersió amb línia de tendència i coeficient de Pearson.}
\label{fig:dashboard3}
\end{figure}

El panell de correlació permet analitzar la relació entre les dades de precipitació de les estacions meteorològiques i els nivells dels embassaments més propers. Inclou un gràfic de dispersió amb línia de tendència i el càlcul del coeficient de correlació de Pearson, proporcionant una mesura quantitativa de la relació entre les dues variables.

\subsection{Matriu d'alertes de sequera}

\begin{figure}[ht]
\centering
\includegraphics[width=\textwidth]{Figures/captura_dashboard4.png}
\caption{Dashboard d'alertes de sequera: taula amb indicadors semàfor i fletxes de tendència per a cada embassament.}
\label{fig:dashboard4}
\end{figure}

El panell d'alertes presenta una taula amb tots els embassaments i el seu estat de sequera actual, utilitzant un sistema semàfor (crític <20%, avís 20-50%, normal 50-75%, òptim >75%). Cada indicador inclou una fletxa de tendència que mostra si la situació està millorant, empitjorant o estable respecte als últims 7 dies.
